# Project Work Rules

- Trabaja exclusivamente con los archivos locales de `XRlab_IFC` abiertos en Visual Studio Code. No cambies de directorio para trabajar sobre otra copia del proyecto.
- No consultes GitHub ni repositorios remotos. No ejecutes comandos Git ni realices operaciones de ramas, commits, push, pull, fetch, merge, rebase, reset o checkout. No uses Git para obtener, comparar, actualizar o recuperar código.
- En auditorías y diagnósticos, limita el trabajo a leer y analizar el código local; no modifiques archivos. Presenta hallazgos con evidencias.
- Antes de editar, indica qué archivos locales cambiarías, qué problema resolverías y los riesgos. Espera autorización explícita del usuario antes de modificar archivos.
- No instales dependencias, ejecutes migraciones o conversiones IFC, ni despliegues el proyecto sin autorización explícita.
- No leas ni reveles el contenido de `.env`, credenciales, tokens u otros secretos.
- Conserva intacto el IFC original; no lo dividas en varios archivos. Preserva las funciones existentes del visor, incluidos cortes, mediciones y controles de cámara.
- Evita consultas innecesarias a la terminal, lecturas repetitivas y análisis de archivos minificados cuando no sean necesarios.
- Al investigar IFC, FRAG, That Open Engine y Three.js, verifica la arquitectura, las dependencias y las APIs locales reales. No supongas compatibilidad con streaming o carga incremental sin evidencia ni afirmes resultados que no hayan sido probados.
